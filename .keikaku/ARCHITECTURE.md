## Stack
**Vite + React + TypeScript** (`vite-react-ts`)

The project requires a responsive and fast web UI with complex features like filtering, grouping, and drag-and-drop. Vite + React + TypeScript is well-suited for building such an interactive and performant application.

## Outcomes this must support
- General Layout
- Add to Library
- View Library
- View Library - Filter
- View Library - Groups
- View Library - Series
- View Library - Author
- View Library - Extras
- View Book
- Search for a Book
- Search - Add Book
- View Library - Filter Wanted Books
- View Series

## Non-functional requirements
- Responsive and Fast
